What I have built

ICT Flux

LivePrivate code

Trading-signal web app · ictflux.app

A rules engine that reads forex, index and synthetic markets from Deriv's live WebSocket feed and says what a published trading method (ICT) would do: the entry, the stop and the target, or to stand aside, with the reason.

  • About 17,000 lines of Python (68 engine modules plus the API), on Vercel serverless functions. The front end is an installable web app (PWA) with push alerts.
  • Accounts and free trial on Supabase, subscriptions through Paystack, MetaTrader 4 and 5 Expert Advisors that read the same signals.
  • Over 690 automated tests. One of them fails if the engine starts trading random prices.
  • An offline tool that checks whether the rules have an edge (walk-forward testing, bootstrap intervals). I tested the tool itself on data with a planted edge and on pure noise.

Not proven profitable. Measured on 19 markets of real candles, the rules have shown no reliable edge yet. The app shows every trade it took and makes no return claims.

Video Splitter & Assembler

Public code

Browser video editor · github.com/Olumidenana/video-assembler-saas

Trim, split, caption and stitch video in the browser. The processing runs on the user's device (FFmpeg.wasm and Whisper), so there is no render queue and no server time limit.

  • Next.js 16, React 19 and TypeScript, about 16,700 lines.
  • On-device captions, a clip finder that scores segments, and free-text edit commands through the Claude API.
  • Supabase sign-in and database. Monthly plans in naira through Paystack (initialise, verify, webhook). Upload to YouTube and TikTok over OAuth.
  • One design decision worth reading: multi-threaded FFmpeg needs cross-origin isolation, which also blocks Paystack's checkout popup. So isolation applies only to /editor, and entering or leaving it is always a full page load.
  • 197 tests, all passing.

ToonForge

PrototypePrivate code

Story-to-cartoon studio

Turns a story idea into a planned, animated episode in the browser.

  • Next.js and TypeScript, about 5,300 lines: story planning with Gemini or Claude using the user's own key, a 2D animator (puppets, sets, camera, music, MP4 export) and spoken dialogue from an on-device text-to-speech model in a Web Worker.
  • A Python FastAPI worker, about 600 lines, for GPU image and video generation with open models, behind a token-protected job queue.
  • 38 tests, all passing.

Status: the browser animator works. The voices and the GPU worker have been tested in mock mode only, not yet on real hardware.

Chopos

PrototypePrivate code

Ordering and settlement for food vendors

A storefront per vendor, a kitchen dashboard, stock counts that update as orders arrive, WhatsApp stock commands, Paystack split payments and a delivery-dispatch adapter.

  • Next.js 14 and TypeScript, about 7,300 lines. Prisma and PostgreSQL with 12 models and 13 API routes.
  • Stock updates use SQL row locks so the same item cannot be sold twice.

Status: runs in demo mode without API keys. No automated tests yet.

Public code
